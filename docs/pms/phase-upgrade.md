# Engineering change register

## Phase 1
- P1.1 — Decimal HALF_UP helpers cover commercial, confirmation, KPI achievement, competencies and merit percentages. The commercial confirmation fixture yields 3.995 before rounding and 4.00 after rounding. **Needs HR approval (DEC-04)**: retain existing Track B band comparison after rounding attainment to two decimals, and Track A threshold comparison on unrounded attainment. Historical scores are preserved.
- P1.2–3 — EPMS_LOCAL_LOGIN=off disables password login. Configuring the SSO verification key requires gateway sign-in for any account granted admin, PM, auditor or Finance. Supply EPMS_ADMIN_SUBJECT for bootstrap. Temporary passwords must change before accessing data. Sessions expire after 30 minutes idle or eight hours absolute. Per-account and direct-peer throttles coexist with a three-per-peer hashing limit. A shared reverse proxy counts as one peer; size and measure sign-in throughput behind the intended gateway.
- P1.4 — Each existing integration token environment variable accepts comma-separated active secrets. Add the new token, restart, move the consumer, then remove the retired token and restart. EPMS_INTEGRATION_IPS accepts comma-separated direct-peer addresses. Each integration authentication writes an audit event. Restrict direct service access at the gateway.
- P1.5 — Each confidential response version is protected by a dedicated data key and stored separately from general entities and snapshots. Set EPMS_FEEDBACK_KEY to an independent 32-byte base64 wrapping key before first startup. Without it the local service creates a private binary key beside the database. Back up the wrapping key separately, alongside existing recovery keys. Restore to staging before migration. Run npm run rekey to rotate the wrapped data key and re-encrypt all response versions in one transaction. Older backups retain their original historical ciphertext.
- P1.6 — Backup destination is created exclusively with owner-only permissions before SQLite begins writing.
- **Needs HR approval (DEC-02/DEC-21)**: the supplied policy uses rater-category weights; PRD v4.2 requires signed authority for equal individual weights and cadence changes in production. Keep that authority with the approved policy version.
